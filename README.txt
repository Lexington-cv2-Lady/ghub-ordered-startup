# G HUB 有序启动

解决 Logitech G HUB 的一个长期未修复的启动顺序 bug。

## 这个工具解决什么问题

G HUB 由多个进程组成，其中两个关键进程必须按特定顺序启动：

```
lghub_agent.exe   →   lghub_updater.exe   →   lghub.exe
```

**如果 updater 比 agent 先启动，G HUB 会卡在启动界面无法使用。**
罗技至今没有修复这个问题，它是概率性的（有时正常、有时卡死），
所以很多人会误以为是"软件坏了"而反复重装。

本工具在启动前先停掉 Updater 服务、杀光所有残留进程，
再严格按上述顺序重新拉起，并**校验实际启动顺序**，避免卡死。

## 快速开始

1. 解压到一个**固定的目录**（不要放在临时目录或压缩包里直接运行）。
   建议路径不含中文以外的问题字符都可以，例如 `D:\Tools\G_HUB有序启动\`。
2. 双击 **`Start-GHUB.cmd`**
3. 首次运行会：
   - 弹出 UAC 请求管理员权限 → 请点「是」
   - 询问**是否创建/替换桌面快捷方式**（替换前会自动备份原图标）
   - 询问**是否设置开机自启**（之后可随时用 `Autostart-Settings.cmd` 更改）
4. 之后日常使用：直接双击桌面图标即可。

## 关于开机自启

**默认不开启**，因为不是所有人都需要。要不要开由你决定：

- 开启后：每次登录 Windows，**延迟 30 秒**后自动按正确顺序启动 G HUB
- 延迟 30 秒是为了避开系统启动高峰，避免和开机时的其他程序抢资源
- 计划任务以「最高权限」运行，所以**不会弹 UAC**
- 随时可以用 `Autostart-Settings.cmd` 关闭

## 两种启动模式

- 双击「Start-GHUB.cmd」：正常启动，G HUB 主窗口会打开
- 开机自启（计划任务，带 -Silent）：静默启动，只驻留系统托盘，不弹窗口；
  需要时点托盘图标即可打开主界面

静默模式用 lghub_system_tray.exe --minimized 实现，与 G HUB 自带自启行为一致，
但额外保证了 Agent -> Updater 的正确启动顺序。

## 常见问题

**Q：为什么每次都要弹 UAC？**
A：脚本必须提权才能工作：
- 停止 `LGHUBUpdaterService` 需要管理员权限
- `lghub_agent.exe` / `lghub_updater.exe` 以提权身份运行，普通权限杀不掉

如果不提权，这两步会被系统静默拒绝，脚本表面"成功"但顺序 bug 依然存在。
（开机自启的计划任务不受此影响，因为任务本身配置了最高权限，不会弹窗。）

**Q：会不会误关我的其他窗口？**
A：不会。脚本不主动结束任何窗口——它退出后，窗口由 Windows 自然处理：
双击启动器时控制台随启动器结束而关闭；在已有终端里运行时，窗口属于你自己的终端，脚本不会去动它。

**Q：它会不会影响我的 G HUB 设置？**
A：不会。脚本只做三件事：停服务、杀进程、按顺序启动。
**不碰配置、不碰注册表、不碰板载内存。**

**Q：脚本提示「有步骤未按预期完成」怎么办？**
A：**先打开 G HUB 试一下**，不用急着重跑：
- 能正常打开、鼠标设置正常 → 直接按回车关闭窗口，忽略这个提示
- 打不开 / 卡在启动界面 → 在提示处**按 1**，脚本会自动重跑一次

这么设计是因为 G HUB 的顺序 bug 是概率性的：有时顺序没完全符合预期，
软件依然能正常用。所以判断权交给你，而不是脚本自行判定"失败"。

**Q：脚本会不会影响 G HUB 的自动更新设置？**
A：**不会**。本工具运行时**不读取也不写入**更新配置文件
（`C:\ProgramData\LGHUB\periodic_check.json`）。

想关闭自动更新，建议用**程序自带的开关**：
G HUB →「设置」→「应用程序设置」→ 取消勾选「启用自动更新」。
这是罗技官方支持的设置路径，对任何 G HUB 版本都适用
（该开关与配置文件的 `downloadAutomatically` 字段是同一个值）。

⚠️ **不要**用防火墙封禁 `lghub_updater.exe` 或更新服务器域名来阻止更新。
该组件同时负责按需下载设备资源（各鼠标型号的素材包），
封掉会导致 G HUB 卡在「正在加载资源」界面。

**Q：提示"未找到 G HUB 安装目录"怎么办？**
A：脚本会依次尝试：默认安装路径 → 注册表卸载项 → 模糊匹配。
如果都失败，说明 G HUB 可能未安装，或安装在非常规位置。

**Q：这个工具适用于哪些 G HUB 版本？**
A：启动排序功能是通用的，脚本会自动适配：
- 同时检测到 `lghub_agent.exe` 与 `lghub_updater.exe` → 按序启动并校验顺序
- 只检测到主程序（新版可能已合并组件）→ 自动退回普通启动，不做无意义排序

安装路径也是自动探测的，不写死版本号或路径。

## 卸载

1. 运行 `Autostart-Settings.cmd` → 选 `2. 关闭开机自启`
2. 删除整个文件夹
3. 如果之前替换过桌面图标，删除它即可
   （原版图标备份为 `Logitech G HUB (原版).lnk`，同目录下）

不会在系统里留下任何残留（除了 `%LOCALAPPDATA%\LGHUBOrderStart`
里的一个首次运行标记文件，删掉即可）。

## 技术细节

- 需要 Windows 10 及以上、PowerShell 5.1（系统自带）
- 所有 `.ps1` 文件必须保持 **UTF-8 带 BOM** 编码。
  如果编辑后存成无 BOM，PowerShell 5.1 会按 GBK 解码，中文提示会变成乱码。
- 自动识别安装路径：默认位置 → 卸载注册表项（含产品 GUID）
  `{521c89be-637f-4274-a840-baaf7460c2b2}` → 按显示名模糊匹配
